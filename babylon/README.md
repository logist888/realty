# Проект «Вавилон» — игра

Браузерная табличная RPG, реализованная по мотивам Game Design Document
«Проект Вавилон». Игра полностью клиентская (HTML + CSS + ванильный JS),
без сборки и сервера, прогресс сохраняется в `localStorage`.

## Как запустить

Просто откройте файл в браузере:

```
babylon/index.html
```

Либо поднимите статический сервер из корня репозитория:

```bash
npx serve babylon        # затем откройте http://localhost:3000
# или
python3 -m http.server 8000   # затем http://localhost:8000/babylon/
```

## Что реализовано из GDD

- **9 статов** (Сила, Ловкость, Выносливость, Интеллект, Вера, Ярость, Удача,
  Реакция, Отражение). Каждый растёт **от использования** по геометрической
  прогрессии 0/100 → 0/200 → 0/400 — ровно как в документе (сила от нанесённого
  урона, выносливость от полученного, ловкость от уклонений и т.д.).
- **Вавилонская башня** — хаб со зданиями: Покои героя, Лестница в Небо, Арена,
  Мастерские, Лаборатории, Магазин, Академия, Банк, Совет старейшин.
- **12 миров** (Равнинный … Рай) с их **локациями и мобами** из раздела
  «Локации и мобы» и уровнями сложности 75–200%.
- **Пораундовый бой**: атака по зоне тела + блок зоны, заклинания, эликсиры,
  критические и контрудары, яд и щиты, бегство.
- **Магия**: 4 стихии × 3 направления = 12 заклинаний из раздела «магия».
  Касты повышают уровни стихий/направлений и Интеллект.
- **Ресурсы 1/2/3 уровня** + особые **Золото / Души / Искры**.
- **Крафт**: переработка ресурсов, оружие, броня, бижутерия и бутылки
  (эликсиры/зелья/мази) по рецептам, с топливом-углём для закалки качества.
- **Квесты** Совета старейшин с «градиентом» 10 / 100 / 1000.
- **Монетизация-демо**: Банк меняет премиум-валюту «Души» на Золото и Искры.

## Структура

```
index.html        — разметка и подключение скриптов
css/style.css     — оформление (камень, бронза, башня)
js/data.js        — игровой контент из GDD (статы, магия, миры, рецепты, квесты)
js/state.js       — состояние героя, рост статов, производные параметры, сохранение
js/combat.js      — боевой движок и генерация мобов
js/game.js        — добыча, крафт, магазин, банк, походы, квесты
js/ui.js          — рендер башни, панелей и боя
```

## Цикл игры

1. В **Магазине** добудьте ресурсы «своими руками» (или купите за золото).
2. В **Мастерских** создайте оружие/броню, в **Лабораториях** — эликсиры.
3. Наденьте снаряжение в **Покоях героя**.
4. Через **Лестницу в Небо** идите в поход в один из 12 миров.
5. Побеждайте мобов, добывайте золото, искры, трофеи и формулы заклинаний.
6. Статы растут от действий; выполняйте квесты в **Совете старейшин**.
