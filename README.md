# Реалти — аналог cian.ru

Учебный клон сайта объявлений о недвижимости: поиск, продажа и аренда квартир, комнат, домов и коммерческих помещений.

Акцент — на нежилых помещениях: **кладовые, машиноместа, коммерческая недвижимость** со своими характеристиками и подземными этажами.

## Возможности

- **Типы объектов**: квартиры, комнаты, дома, коммерческие помещения, кладовые, машиноместа. У нежилых — свои характеристики: назначение помещения, тип паркинга, высота потолков, охрана, отдельный вход
- **Этажи от −10 до 100**: подземные этажи для кладовых и машиномест, 0 — цокольный
- **Автоподсказки адреса** при вводе (геокодер Photon / OpenStreetMap, без API-ключа) — выбранный адрес даёт точные координаты
- **Карта Leaflet** на странице объявления с маркером по точным координатам
- **Загрузка фото drag & drop**: перетаскивание нескольких файлов сразу, превью, удаление до отправки
- **Поиск с фильтрами**: тип сделки (купить / снять / посуточно), тип недвижимости, число комнат (включая студии и «4+»), цена, площадь, город, район, станция метро
- **Сортировка и пагинация** выдачи (новые, дешевле, дороже, по площади)
- **Страница объявления**: фотогалерея, характеристики, описание, цена за м², похожие объявления, расположение, счётчик просмотров
- **Телефон продавца** по клику (как на Циан)
- **Ипотечный калькулятор** на странице продажи
- **Регистрация и вход** (sessions, пароли через scrypt)
- **Избранное** с мгновенным переключением без перезагрузки страницы
- **Подача объявлений**: форма с валидацией и загрузкой до 10 фотографий
- **Личный кабинет**: мои объявления, редактирование, снятие с публикации, удаление
- **Демо-данные**: 180 сгенерированных объявлений в Москве, Санкт-Петербурге и Екатеринбурге, около половины — нежилые объекты

## Технологии

Node.js, Express 5, EJS (server-side rendering), SQLite (better-sqlite3), multer, vanilla JS/CSS. Фото-заглушки генерируются на лету как SVG.

## Запуск

```bash
npm install
npm run seed   # заполнить базу демо-данными (однократно)
npm start      # http://localhost:3000
```

Демо-аккаунт: `demo@realty.local` / `demo1234`

## Карта: Яндекс.Карты или OpenStreetMap

По умолчанию карта на странице объявления рендерится через Leaflet + OpenStreetMap
(без ключей). Стандартные тайлы OSM отображают границы по «международной» схеме,
что не соответствует законодательству РФ (Крым, новые регионы).

Для отображения границ согласно Конституции РФ подключите Яндекс.Карты:

1. Получите бесплатный ключ JavaScript API в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/services/) (сервис «JavaScript API и HTTP Геокодер»)
2. Запустите сервер с ключом:

```bash
YANDEX_MAPS_API_KEY=ваш-ключ npm start
```

При наличии ключа карта автоматически переключается на Яндекс.Карты.

## Структура

```
server.js            — точка входа, маршрут SVG-заглушек
src/db.js            — схема SQLite
src/queries.js       — поисковые запросы с фильтрами
src/auth.js          — хеширование паролей, middleware сессий
src/helpers.js       — словари (города, метро, типы), форматирование
src/seed.js          — генерация демо-данных
src/routes/          — auth, offers (поиск/просмотр/API), cabinet (кабинет)
views/               — EJS-шаблоны
public/              — стили и клиентский JS
data/                — база и загруженные фото (не в git)
```
